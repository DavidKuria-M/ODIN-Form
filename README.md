## Sign-Up and Login Form

A responsive sign-up and login form built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form) curriculum. This project focuses on creating clean, user-friendly form interfaces using HTML and CSS, with an emphasis on layout, form styling, input validation, and responsive web design.

### Features
- User-friendly sign-up and login interfaces.
- Clean and modern UI design.
- Form input fields with appropriate labels.
- Responsive layout for different screen sizes.
- Accessible and well-structured HTML.

### Technologies Used
- HTML5
- CSS3
- JavaScript

This project strengthens my front-end development skills and understanding of form design, styling, and user experience as I progress through The Odin Project curriculum.
